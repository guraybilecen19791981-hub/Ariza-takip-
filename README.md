# Arıza Takip (Android demo)

## 1. Firebase kuralları (bir kez)
Firebase konsolu → Firestore Database → **Rules** sekmesi → içindekini silip `firestore.rules` dosyasının içeriğini yapıştırın → **Publish**.

## 2. APK
GitHub → **Actions** → en son "APK derle" çalışması → sayfanın altındaki **ariza-takip-apk** → zip içindeki `app-release.apk`.

## 3. Kurulum ve ilk giriş
1. APK'yı telefona atıp açın, "bilinmeyen kaynaklara izin ver" deyin.
2. Admin (guraybilecen19791981@gmail.com) "Yeni hesap oluştur" ile kayıt olur, otomatik admin olur.
3. Diğer kişiler de kendi telefonlarında kayıt olur; admin **Kullanıcılar** sekmesinden rollerini verir.
4. Alarm alacak telefonlarda: bildirim izinlerine izin verin, üstteki pil simgesinden pil kısıtlamasını kaldırın.
